3. 主模型训练 + 测试
--------------------

python MMHF.py 会：读配置 -> 5 折划分 -> 每折训练 -> 加载该折 best checkpoint -> test 推理 -> 汇总指标。

3.1 正式 5 折实验（推荐，cuda:0）

  # PowerShell
  $env:CUDA_VISIBLE_DEVICES = "0"
  python MMHF.py

  # cmd
  set CUDA_VISIBLE_DEVICES=0
  python MMHF.py

默认使用 config/config2.json（若不存在或路径无效，再尝试 config/config.json）。
配置中 device 已设为 cuda:0；代码会 torch.cuda.set_device(0)。

指定配置：

  # PowerShell
  $env:CUDA_VISIBLE_DEVICES = "0"
  $env:MMHF_CONFIG = "config/config2.json"
  python MMHF.py

  # cmd
  set CUDA_VISIBLE_DEVICES=0
  set MMHF_CONFIG=config/config2.json
  python MMHF.py

或用消融脚本的 main 入口（输出可单独指定）：

python experiments/run_ablation.py --config config/config2.json --experiment main --variant full --fold all

3.2 快速冒烟（1 折、1 epoch）

python experiments/run_ablation.py --config config/config2.json --experiment main --variant full --fold 1 --epochs 1 --output_dir checkpoints_smoke/main

3.3 只跑某一折

python experiments/run_ablation.py --config config/config2.json --experiment main --variant full --fold 1 --output_dir checkpoints_mmad_mci_fold1

多折示例：--fold 1,2,3


4. 关键配置项（config/config2.json）
-----------------------------------

  device                          主训练用 cuda:0（无 CUDA 才回退 CPU）
  num_epochs                      每折训练轮数（默认 100）
  batch_size                      默认 4；显存不足可改 2
  lr / weight_decay               优化器超参
  checkpoint_dir                  输出目录（默认 checkpoints_mmad_mci）
  use_mri / use_pet / use_table   模态开关
  use_shared_layer / use_channel_exchange
                                  图像分支 CEN/共享层
  use_hypergraph_conv / use_hypergraph_attention
                                  超图分支
  roi_start / roi_end             ROI 范围（论文默认 1-90）
  use_seg_task / seg_task         辅助分割 loss


5. 输出文件
-----------

训练目录（默认 checkpoints_mmad_mci/）：

  best_model_fold{k}.pth          第 k 折最佳权重（{"model": state_dict, "tab_dim": ...}）
  fold{k}_metrics.csv             每 epoch 的 train/val 指标
  test_results.txt                各折测试指标
  result.csv                      逐样本：fold, sample_id, true_label, pred_label, prob_pmci
  fold_indices.json               五折划分索引
  tabular_preproc_fold{k}.joblib  该折表格预处理器

终端最后会打印各指标的 5 折 mean +/- std（含 BACC）。

7. 用已训练模型只跑 ADNI 测试集（不重新训练）
---------------------------------------------

前提：checkpoint 目录里有 best_model_fold{k}.pth，以及训练时生成的 fold_indices.json。

当前你这边已有示例：
  checkpoints_mmad_mci/best_model_fold1.pth

# PowerShell：用 cuda:0 评估第 1 折测试集
$env:CUDA_VISIBLE_DEVICES = "0"
python scripts/eval_adni_test.py --config config/config2.json --checkpoint_dir checkpoints_mmad_mci --fold 1

# 评估该目录下所有折（缺的折会 Skip）
python scripts/eval_adni_test.py --config config/config2.json --checkpoint_dir checkpoints_mmad_mci --fold all

# 指定单个权重文件
python scripts/eval_adni_test.py --config config/config2.json --checkpoint checkpoints_mmad_mci/best_model_fold1.pth --fold 1

输出（写在 checkpoint_dir 或 --output_dir）：
  test_results_eval.txt   各折测试指标
  result_eval.csv         逐样本预测（含 prob_pmci）

# 在验证集 val 上评估（不是 test）
python scripts/eval_adni_val.py --config config/config2.json --checkpoint_dir checkpoints_mmad_mci --fold 1

输出：
  val_results_eval.txt
  result_val_eval.csv

说明：划分必须与训练时同一套 fold_indices.json，否则会数据泄漏/不可比。

9. 说明
-------

1. 完整训练 python MMHF.py 结束时已经会自动跑测试集；结果在 checkpoints_mmad_mci/test_results.txt 与 result.csv。
2. 若只想对已有权重再测一遍，用第 7 节的 scripts/eval_adni_test.py。
3. 表格特征默认按折在 train 上 fit（feature_schema=full133），无需预生成 embedding。
4. 若要改轮数/batch，可直接改 config/config2.json，或用 run_ablation.py 的 --epochs / --batch_size 覆盖。
